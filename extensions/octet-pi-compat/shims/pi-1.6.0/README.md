# Pi 1.6.0 helper sources

`UPSTREAM.json` records the reference commit and the sha256 of every reviewed
dist file the shims bind or classify for Pi 1.6.0; `../manifests/1.6.0.json` is the
capability manifest that names them. Routes and classifications are unchanged
from 1.5.0; the manifest's `reference.notes` and `delta` say what changed for
extensions in this release.
