# octet 0.8.0 candidate qualification

This is an unreleased source candidate, not a signed release or a claim of
live-provider, physical-terminal, native-device, or daily-driver acceptance.
Checks run in an isolated checkout, including the scoped existing work. The
original checkout and installed binaries are not the verification environment.

## Release-gate scope

- Extension initialization and actual Rust-host/Python protocol roundtrips.
- Owner-bound worker recovery, continuation, deadlines, and safe reload refusal.
- Foreground terminal input ownership and complete native transcript history.
- Bounded shell captures, editor history, provider arguments, and safe file reads.
- Provider request correctness, interrupted-answer separation, retrieval
  cancellation, image-error redaction, MCP framing, and ordered event-bus ACKs.
- Retained Pi migration/import, with the executable compatibility bridge removed.
- Current public documentation, package metadata, and reviewed model snapshots.

## Limits

Native iOS/macOS companions remain source-only. Layout proportionality, Mermaid
grapheme placement, notification wording, live providers, external MCP services,
browser authentication, full Serve frontend/device acceptance, and long-duration
soaks are not qualified by these checks. Not every review finding is resolved.

Resource rebuilds refuse while host worker tasks remain attached, including
retained idle receivers. Force/watch reload cannot bypass ownership. Finish or
stop work, then exit and resume the session to replace that host; no live worker
handoff is promised. Historical roster updates and structural terminal changes
may still require a complete replay, but must not omit conversation rows.

No merge, tag, publication, installation, or repository-visibility change is part
of preparing this pull request.
