# Local 0.8.0 reduction candidate

This is a **local, unreleased candidate**, not a signed release or a claim of
live-provider, cross-platform, or one-week daily-driver qualification. Product
version stays `0.8.0`; the last public release remains `0.7.6`. Extension API
versions and native-host protocol are not renumbered. Existing provider, import,
permission, and session contracts remain.

## Scope and release boundary

The first three approved passes were:

1. Establish retained-workflow regressions and a before-change baseline.
2. Retire Pi parity and the all-capabilities platform as public commitments.
3. Remove the dedicated Pi compatibility bridge and `octet pi` command, while
   retaining ordinary providers, `octet migrate pi`, and import adapters.

The retained integrations are Browse, MCP, subagents, web-search, and the separate
Serve application. MCP still needs dynamic tool registration; subagents still
need host-owned child sessions. Generated schemas, SDK code, and conformance
checks remain live dependencies, not deletion targets. The historical
Compact/performance pass and subsequent theme removal are recorded separately
below; neither broadens this local candidate into a public release or
live-provider qualification.

## Remaining qualification

- Real-terminal visual/daily-driver qualification is still outstanding. The
  synthetic PTY redraw matrix now passes, but it does not reproduce every
  terminal, multiplexer, or the exact reported screenshot conditions.
- The bootstrap suite exposed cross-test interference in the unchanged global
  readiness-observation vector (`app/bootstrap.rs`): the parallel run had one
  failing assertion; the failing test alone and all 131 runnable bootstrap tests
  serially passed (one separate test ignored). No provider behavior or test
  assertion was weakened. Parallel isolation still needs a later fix/review pass.
- Full-workspace lint/CI, the complete TUI matrix, live providers, external MCP
  services, browser authentication, full Serve frontend acceptance, and the
  one-week daily-driver run are not claimed by these local checks.

The final optimized binaries must pass isolated `--version`/help/migration
checks and native-host hello/shutdown before replacing the user-global install.
The installer keeps rollback copies of both old binaries and managed docs;
existing extensions, sessions, configuration, and credentials are untouched.
Installation measurements and hashes are retained with the local operator's
run artifacts, not presented as a published release or benchmark win.
