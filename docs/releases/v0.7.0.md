# octet 0.7.0 — unreleased

<!-- Private release-body proposal only; this authoring pass does not publish it. -->

**Unpublished and not release-qualified.** These notes describe the frozen
documentation draft `30df0ae36309cc00e160`, not final provider or migration
implementation. Live-provider, media, recovery, and product-capture qualification
remain outstanding; source fixtures are not completed demonstrations.

Use the [local checkout build](../../README.md#install). The source and release
repository remains [skaft-software/ygg](https://github.com/skaft-software/ygg).
No public octet download, registry package, Homebrew tap, or repository cutover
is asserted. Bun is unqualified.

## Added

- Repository documentation, usage examples, and the [Brand Kit](../assets/octet/README.md).

<a id="current-source-identity"></a>

## Changed

- Adopted the lowercase octet name, `octet` and `octet-host` binaries,
  `octet-*` packages, `OCTET_*` settings, and `.octet` directories. Packaged
  documentation uses `share/octet`.

See [package identities](../distribution.md#package-identities) for the exact
source crate, import, package and protocol names.

In this snapshot, existing Ygg installations and data remain separate. There
are no old command or `YGG_*` aliases, `.ygg` fallbacks, or automatic Hamr/Ygg
credential or package-hotfix imports. Third-party `~/.codex/auth.json`
interoperability and explicitly invoked Pi import/restore retain their original
source stores without modification.

<a id="integrated-corrections-and-evidence-boundary"></a>

## Fixed

The frozen draft records fixes for:

- Provider-start retry handling.
- Typed-media validation and local-compaction replay.
- Narrow terminal layouts and duplicate startup rendering.

These notes do not qualify final provider behavior, full Pi parity, or current
octet benchmarks. Local compaction remains the default in this snapshot.

## Extension compatibility

Current authoring documentation targets extension API 0.3. The four bundled
executable-extension manifests still declare 0.2, and the Python `Extension`
runtime remains a legacy 0.1/0.2 implementation. Generated 0.3 types are not a
complete Python 0.3 runtime. Native-host protocol 1 is independent of extension
API versions. See [extension authoring](../extensions.md) and the
[native host reference](../sdk.md); these notes do not claim runtime parity.
