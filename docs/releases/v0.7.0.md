# octet 0.7.0 — draft, unreleased

[Documentation](../README.md) · [Workflows](../workflows.md) · [Changelog](../../CHANGELOG.md)

**This document describes intended identity and remaining qualification work,
not a published release or a release-ready candidate.** The source repository
remains [skaft-software/ygg](https://github.com/skaft-software/ygg).

## Product identity

**octet is the high-performance coding agent, extensible in any language, free
and open source.** Use lowercase `octet` in product prose. The native agent loop,
language-neutral extension boundary, and durable sessions support repository
work, domain tools, bounded delegation, and application embedding.

The [canonical marks and wordmark](../assets/octet/README.md) are identity source
assets. They are not captures of a running branded terminal or web candidate.
The [workflow guide](../workflows.md) links existing examples and implementation
contracts to substantial build/use/delegate/embed outcomes. Those recipes still
need exact-candidate end-to-end evidence.

| Repository | `https://github.com/skaft-software/ygg` | Unchanged unless separately authorized |

The rename is intended to be clean: no Ygg command aliases, legacy-root
fallbacks, or automatic old-brand migration. Preserve unrelated installed Ygg
binaries, configuration, credentials, sessions, and data. Historical releases,
benchmark artifacts, and third-party copyright/provenance retain their original
identity. Pi compatibility is a separate bounded capability contract, not an
old-brand migration mechanism or a promise of full Pi parity.

Use [current checkout build instructions](../../README.md#build-this-checkout)
for source inspection. Do not substitute `octet` into an install URL, package
scope, Homebrew formula, executable, or SDK import until that exact surface has
been renamed and verified. No octet publication channel is asserted here.

## Required evidence before release readiness

These are outstanding gates, not a list of checks that passed:

The source audit distinguishes direct OpenAI HTTP Responses from Codex's
WebSocket-preferred route and zstd HTTP fallback; Responses Lite explicitly
sets `parallel_tool_calls: false`. Local compaction remains the product default,
and a process-local WebSocket continuation ID is not durable session recovery.
The [current reference](../current-reference.md#provider-and-protocol-support)
records these boundaries. The inherited unsafe agent body-disconnect retry still
requires its removal to be integrated and regression-checked, even for failures
before visible output. Media and consent corrections are also underway and
unqualified. Deterministic primitives do not establish completed user outcomes,
live endpoint behavior, or actual branded captures.

- Finish the coherent executable/host/crate/SDK/environment/root/version rename,
  package metadata, generated contracts, embedded docs, and install workflows.
- Run exact-source format, build, lint, tests, dependency/security, generated API,
  SDK, web, packaging, and relevant workflow checks on the renamed candidate.
- Record actual provider/tool/read/edit/cancel/queue/recovery/session/media/privacy
  behavior and an explicit provider/Pi/extension support matrix. Live endpoint
  behavior cannot be inferred from model names or deterministic fixtures.
- Reproduce the substantial workflows with reviewed outputs, exact source and
  model identities, permissions, failures, and durable evidence. Capture actual
  branded TUI and web behavior with private information removed.
- Verify the installable unpublished release-profile `octet` and `octet-host`,
  optional Serve, and claimed packages on macOS arm64, macOS x64, and GNU/Linux
  x64. Unavailable platform or live-provider evidence remains an explicit blocker
  or authorized disposition, never a pass.
- Review canonical asset manifests/checksums and the public identity package;
  keep benchmark archive contents, redistribution/privacy limits, and historical
  provenance explicit. An evidence ZIP must not imply missing raw trajectories
  or unmeasured candidate comparisons are included.
- Complete independent full-candidate review and exact-head fixes/rechecks.

Until these gates are evidenced, there is no release-readiness claim, stable
installation promise, or implied issue closure. Publication, tags, repository
changes, and external website deployment require their own authorization.
