**This checkout declares octet 0.7.0 source metadata. It is unpublished and not
yet release-qualified.** The actual source and release repository remains
[skaft-software/ygg](https://github.com/skaft-software/ygg); no remote repository
cutover, registry availability, or public download is asserted.

## Start with sound, then build tools, delegate audits, or embed an assistant

**octet is the high-performance coding agent, extensible in any language, free
and open source.** The native loop, language-neutral subprocess extensions,
and append-only sessions support substantial repository work:

Start with the [audio-led reference recipe](../workflows.md#start-with-an-audio-reference):
attach WAV/MP3 through a model-capable OpenAI Chat route, optionally compare
images, and review a brief before implementing it. Explicit chips, format/size
limits, unsupported failures, and session privacy are part of the
[media contract](../current-reference.md#multimodal-prompts). Serve web audio is
not implemented. Gemini 3.8 Flash remains proposed, not qualified. This audio
story and the three original workflows below still need actual outcome evidence:

- [Build, use, and reuse a repository-contract tool](../workflows.md#2-build-and-use-a-domain-extension)
  with a bounded schema, tested handler, explicit selected-source trust, and
  results the agent can use on the next turn.
- [Delegate two independent audits](../workflows.md#delegate-independent-investigations),
  verify and integrate their unique findings, then continue a useful worker in
  its durable session. Workers inherit the parent model; read-only grants are
  explicit, and shared cwd is not isolation.
- [Embed a durable read-only repository assistant](../workflows.md#3-embed-a-read-only-repository-assistant)
  through `octet-host`: negotiate protocol 1, stream a run, and resume a follow-up.
  This host does not start executable extensions and its Controlled policy
  denies mutation, process, and delegation authority.

These are reproducible source recipes, not completed model-driven stories.
Actual reviewed outcomes and sanitized branded TUI/web captures remain gates.

This is a clean first-party namespace break, not a compatibility alias. There
are no Ygg commands, old `YGG_*` readers, `.ygg` fallbacks, or automatic
Hamr/Ygg credential or package-hotfix imports. Existing installations and data
remain separate. Third-party `~/.codex/auth.json` credential interoperability
and explicitly invoked Pi import/restore remain supported; original source
stores are never modified. Historical releases, measurements, upstream
copyrights, Pi pins, independent example versions, and mismatch fixtures keep
their original scope.

The Python `Extension` runtime still adapts APIs 0.1/0.2; generated 0.3 types do
not create a 0.3 Python runtime. Renaming first-party wire fields such as
`octet_version` does not renumber the APIs or preserve old-name aliases.
Use the [local checkout build](../../README.md#build-this-checkout), not an
invented octet installation URL. [Distribution machinery](../distribution.md)
is source implementation, not a launched npm or Homebrew channel.

## Integrated corrections and evidence boundary

The integrated source keeps response-body disconnects terminal even before
visible output; absence of text does not prove replay is safe. Direct OpenAI
uses HTTP/SSE Responses, while Codex prefers WebSocket with HTTP fallback and
configured zstd compression. Responses Lite explicitly sends
`parallel_tool_calls: false`; a process-local continuation ID is not durable
session recovery. See [provider contracts](../current-reference.md#provider-and-protocol-support).

Media, consent, and local-compaction corrections are integrated and covered by
deterministic regression fixtures: bounded typed input and payload-free
presentation, ordinary typed paths not treated as upload consent, safe approval
presentation, and encrypted Responses tail retention across local compaction
and resume. Local compaction remains the default, not native Responses mode.
These are fixture-backed implementation facts, not live-provider qualification,
full Pi parity, or successful model-driven demonstrations.

The [canonical identity package](../assets/octet/README.md) supplies the
`01101111` byte mark, outlined wordmark, provenance, and checksums. Native/web
consumers use that identity; asset proofs and fixture screenshots are not
actual accepted product captures. The small [historical evidence package](../assets/evidence/README.md)
retains Ygg v0.6.2 attribution, audit exclusions, and redistribution limits.
There is no current octet benchmark or Claude Code token/RAM comparison claim.

  Serve and claimed packages, qualified on macOS arm64, macOS x64, and GNU/Linux
  x64. Native terminal/theme/resize/input and host-connected web acceptance
  remain required. Missing platforms are blockers or explicit dispositions,
  never inferred passes.
- Asset-manifest and public evidence-package review, preserving historical
  provenance and privacy/redistribution limits without implying raw trajectories
  or unmeasured comparisons are included.
- Fresh independent full-candidate review, fixes, and exact-head rechecks.

No release-readiness claim or implied issue closure follows from source metadata.
