# octet 0.9.0

This release delivers the current native coding agent without the experimental
Pi compatibility extension. The [version-pinned release page](https://github.com/skaft-software/octet/releases/tag/v0.9.0)
records the immutable source, CI runs, artifact checksums and actual channel
availability. Source-build evidence is not public-artifact qualification.

## Highlights

- **Native coding surface:** `read`, `edit`, `write` and `bash` (PowerShell
  on Windows). Independent reads and shell calls can overlap under full access;
  mutations and approval-bearing calls remain ordered. Native Search is removed;
  content search uses `rg` or `grep` through the shell.
- **Interactive correctness:** model and reasoning changes wait for a safe
  request boundary; settings apply visibly; paste and attachment chips remain
  editable text with undo. Fullscreen scrolling retires stale Kitty images.
- **Provider setup and discovery:** review-first API-key, subscription and local
  endpoint setup; explicit removal of saved providers/sign-ins; live OpenCode
  inventories; bounded background discovery when the model is already known.
- **Sessions and presentation:** resumable histories, busy steering/follow-up,
  selectable built-in themes, transcript selection/copy and Tern native surfaces.
- **Optional integrations:** five separately installed bundles: codemode,
  computer use, MCP, subagents and web search. Installation never enables an
  extension, grants trust or provisions its optional dependencies.

## Changed

- Product, SDK source and the five shipped extension manifests use **0.9.0**.
  Extension API versions remain independent; bundled extensions require the
  exact host version `=0.9.0`.
- Removed the packaged Serve application, its web/Apple companions, the native
  Search tool and the obsolete browser extension.
- The interactive terminal defaults to fullscreen with app-owned mouse input.
  `--mouse auto` retains inline terminal scrollback.
- Provider-request tracing is opt-in and redacts prompt, credential and output
  contents. Only the newest four tool-result images are sent to the model.

## Qualification

| Surface | Qualification boundary |
| --- | --- |
| Rust workspace, SDKs and shipped integrations | Exact-source automated CI; final run and result recorded on the release page |
| Linux/macOS native archives | Clean release builds, version/host smoke, repeatable packaging, checksums and Sigstore verification; public-install receipts belong to the published artifacts |
| Windows MSVC archive | Release-workflow native runtime, terminal and extracted-executable ConPTY checks; GNU CI alone does not qualify MSVC |
| Terminal/model behavior | Loopback-provider and PTY evidence, not paid-provider or physical-display acceptance |
| Pi compatibility | **Excluded**, not offered in the release catalog and not qualified as a shipped feature |

Prior candidate runs and local development tests are not evidence for a different
release SHA. The release page distinguishes completed gates from pending or
unrun acceptance; a successful build alone is not a passing coding-task smoke.

## Known limitations

- **Pi compatibility does not ship.** `octet-pi-compat` remains source-only
  experimental work. Installed-Pi lifecycle/command parity, dependency-bearing
  workflows and cold mirror startup are not release qualifications. Previously
  installed experimental adapters are not automatically removed or enabled;
  disable them explicitly if present. Built-in Pi-themed palettes, migration
  utilities and codemode are separate from this adapter.
- **Live provider, subscription and audio acceptance is not run for this
  release.** Mock-provider tests do not establish account/model availability,
  billing accuracy or real audio behavior. The reported Windows Codex HTTP 400
  issue ([#572](https://github.com/skaft-software/octet/issues/572)) remains
  unresolved pending a redacted request trace.
- **Attended UI/driver journeys remain unqualified.** Automated terminal-buffer
  and ConPTY checks do not establish physical presentation, trackpad behavior in
  every terminal, or granted desktop-driver behavior.
- **No performance comparison is published.** Historical benchmark records are
  not measurements of this release's final artifacts.
- **Publication channels are independent.** npm, Homebrew, crates.io, SDK
  registries and container registries are not made available by the native
  release workflow. Only channels with explicit receipts on the release page
  should be treated as published.
