# octet 0.10.5

## [0.10.5] - 2026-11-19

### Added

- Click the composer to place the cursor, and drag to select and copy, as in a real text box.
- Fullscreen selection copies on release, keeps extending while you scroll or output streams, and copies replies as Markdown source.
- Scrolled transcripts show a clickable Jump button with a count of new output.
- Local video goes to image-capable models as four timestamped frames; Gemini receives video natively.
- Rust embedders can use octet's provider, tool and extension-host crates on their own, as described in the provider embedding guide.
- GPT-6.2 Sol and GPT-6.2 Astra are available on OpenAI and Codex, with their API prices and long-context tier.
- Settings can show tool-call and thinking durations. They default to Off in Octet and On in Pi themes.

### Changed

- Wheel and trackpad scrolling move one row per step; Alt+wheel moves 15.
- The fullscreen transcript scrollbar stays thin on hover and drag, and Auto mode leaves transcript wrapping unchanged.
- The model picker shows provider names as group headings instead of repeating them on every row.
- Working and Thinking keep a steady height with room for a summary, and the blank line above stays outside shaded prompt cards.
- With durations on, completed thinking can show a muted `• Thought for 15s` marker. Ctrl+T reveals the trace regardless of the setting.
- The splash is a compact two-line mark with the version, access mode and `/changelog`.
- Faster clicks on the terminal splash quicken the rainbow and the eyes' blink; both ease back to rest when clicks slow or stop.
- Composer overflow counts sit in the border, leaving more room for your draft.
- Codex uses provider-default context windows, keeping the 500K windows of GPT-6.1 Sol and Terra.
- With durations on, native tool cards can show a `└ Took …` row aligned with the output elbow.
- Live shell cards show activity with the event dot, without a redundant status line.
- The Pi presentation profile adds a composer-rule spinner, effort-colored rules, a two-line footer, and configurable native tool cards.
- Extension slash commands and shortcuts run immediately during a response.
- Large tool-call batches run in bounded concurrent waves.
- Recorded audio is prepared once and reused across turns; large Gemini clips upload through the Files API.
- Shortcut hints, pickers and `/hotkeys` use consistent `Ctrl+T`-style labels.
- The footer marks subscription-only estimates `(sub)` and combined API and subscription spend `(mixed)`, regardless of the selected model.
