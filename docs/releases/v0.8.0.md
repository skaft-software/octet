# octet 0.8.0

## Fixed

- Keep `/goal` and inspection/picker slash commands responsive during streaming.
- Keep startup silent and editable, with model-context notices deferred until terminal teardown.
- Give activity shimmer a visible luminance sweep and preceding dot pulse, with a complete sweep/rest phase and neutral model identities.
- Display plain-dollar footer costs without weakening durable usage uncertainty or budget accounting.
- Settle completed workers once into their owning transcript block, without replay on later turns or displacement of scrolled history.
- Repair host-budgeted WebSocket retries, delegated usage reconciliation, ephemeral multi-session accounting recovery, and read-only delegated Serve export.
- Honour documented input modalities and context/output limits for models whose provider publishes a sparse model list, starting with DeepSeek V4.1 Flash (images now attach, and the window is its 1M/384K record instead of the generic 128K/64K placeholder); an endpoint that asserts its own metadata is never overridden.

- Reserve bounded headroom so a request never fills the model's context window exactly, and recover a provider size rejection by compacting once and retrying instead of failing the turn.

- Restore the complete `/model` provider list after a launch pinned a built-in model; startup narrowing no longer hides other configured providers from the picker.

- Read reasoning support from a provider's advertised request parameters so a newly released model gets its thinking levels without a rebuild, and name the reasoning-only failure explicitly.

- Withdraw `/tree` and `/checkout`, and rename `/quit` to `/exit`.

## Changed

- Add live, capability-gated `/fast` priority selection, queued safely during active work, with durable conservative cost uncertainty.
- Consume user keybindings and scoped model cycling; preserve drafts when shortcuts generate commands.
- Add bounded rich Markdown/syntax HTML export, explicit local-model evaluation profiles, session-backed tool checkpoints/memos, and host-accounted summary retries.
- Add a session-isolated negotiated API 0.3 process event bus; this does not grant arbitrary Pi UI or cross-session authority.
- Identify the local Rust build and its first-party Cargo dependencies as 0.8.0.
- Include the reviewed additive provider, codec, tool, editor, CLI and rendering work. The detailed parity ledger distinguishes tested behavior from incomplete primitives.

## Known limits

Pi parity is not complete. Product open-all remains fail-closed until atomic writer claim/settlement exists. `/fast` is process/current-session scoped, does not promise provider acceptance, and retains uncertainty after disabling; real extension theme/UI consumers and broader provider/bridge parity remain incomplete. Formatting, native/live qualification and other gaps remain recorded in `docs/parity/DELIVERY.md`.

## Availability

This is a local build, not a published release. Existing installation links continue to reference the last public version. Building these binaries does not replace an installed copy or authorize release publication.
