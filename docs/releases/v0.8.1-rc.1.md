# Octet v0.8.1-rc.1 — local dogfood candidate

This is an unpublished release candidate prepared for local dogfooding. Build it
from this checkout and run `./target/debug/octet` directly; do not use
`cargo install` or a global installer.

Build command:

```sh
cargo build --offline --locked -p octet-coding-agent --bin octet
```

## Included

- In-session `/setup` provider configuration that preserves the active model and
  session.
- Discovery and selection of user-defined TOML themes in `/theme`.
- Terminal window titles synchronized with the active session name.
- Kitty inline-image cursor handling intended to keep the composer below the
  image.

## Verification and limits

The local debug build was checked to report `octet 0.8.1-rc.1`; the 11 setup
TUI acceptance tests passed, and the focused Kitty transmission-header test
passed. Previously observed broader checks include 1,916 `octet-coding-agent`
library tests (1 ignored) and 242 `sexy-tui-rs` tests. The optimized `--release`
build has not been completed in this environment. The Kitty cursor change still
needs visual confirmation in a Kitty-compatible terminal. This candidate has
not been published, tagged, or installed globally.
