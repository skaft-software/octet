# octet 0.8.2

This release sets up and configures every extension from `/extensions`, adds
GPT-6.1 Sol and browser sign-in for ChatGPT (Codex), lets safe mode run the
extensions you grant, and restores the native Windows build.

This is candidate scope, not a publication receipt. The changes previously
listed under **Unreleased** are included in this 0.8.2 candidate; historical
Windows results below do not qualify its expanded final source.

## Highlights

- **Removed applications and Browse (#492).** Serve, its web client and Apple
  companions, and the deprecated Browse bundle are no longer built or shipped.
  Codemode and the optional Pi adapter remain; computer use operates the user's
  own browser, without an octet-owned isolated browser profile.

- **Local combined RC only.** This source combines #480 with #501 (including
  #495/#498), #492, #493, #494, #496, #497, #499 and the optional #500 preview.
  No merge, tag, publication or cross-platform release qualification is implied.
- **Working-dot shimmer.** The recovered local patch synchronizes the margin
  dot with the label sweep, without changing glyph geometry or no-colour behavior.
- **Tern native UI.** The preserved welcome, composer, model/thinking/context/
  session surfaces and agents HUD are restored, with focus recovery and completed
  tool collapse. `--tern auto|on|off` retains an ANSI fallback.
- **Inference measurements.** Prefer server-reported generation timing; otherwise
  label the client-stream decode estimate explicitly. Neither is a GPU benchmark
  or proof of live-provider accuracy. See [inference metrics](../inference-metrics.md).
- **Provider prewarming.** Accepted headless Responses WebSocket runs can prewarm
  their settled prefix. Anthropic cache warming adds `off|streaming|idle`, separate
  billable maintenance accounting and `/cache-warming` diagnostics. Live savings
  are unverified; choose `--cache-warming off` for credential-free RC testing.
- **Optional tool composition and Pi UI.** Codemode uses the vendored offline
  QuickJS/WASM runtime through host-scoped tool composition. The Pi adapter is a
  source preview, not general API parity; custom-editor rescue and the unchanged
  `pi-clm` acceptance target remain unqualified. Both require explicit enablement.
- **Startup/resume improvements.** Indexed inventories, canonical Markdown reuse
  and bulk history publication retain complete native scrollback. Prior branch
  benchmarks do not establish a performance improvement for this combined RC.

- **Paid-plan sign-in.** Grok, Kimi, Meta and OpenRouter have separate OAuth
  subscription providers without replacing configured API keys. Device flows
  support headless use; Meta retains its identity token across API-key renewal.
  Anthropic subscription support is deliberately not included.
- **Complete native terminal updates.** Resize and historical changes above
  the old viewport clear and replay the complete canonical transcript, rather
  than leaving snapshots or skipping newly accepted rows. Resize bursts settle,
  height-only wrapping is reused, the welcome stays static, and cursor placement
  remains inside synchronized frames.
- **Concise mutation results.** Write/edit diffs live in durable UI metadata,
  not model context; JSON escaping is bounded and output is validated before
  committing a file.
- **Everything in `/extensions`.** Choosing an extension opens its options menu:
  - set up computer use end to end;
  - choose Brave Search or SearXNG for web search;
  - manage subagent workers;
  - add, edit or remove MCP servers through a guided form.

  Actions show their steps live and can be cancelled with Esc. Extension slash
  commands are gone from the terminal UI; typing one names the extension to
  open instead.
- **GPT-6.1 Sol.**
  - On ChatGPT (Codex) sign-in it leads the fallback model list and starts at
    low reasoning. Ultra appears only when your account advertises it.
  - On an OpenAI API key it offers low through max reasoning, a 1.05M-token
    context and 128K output tokens.
- **Browser sign-in for ChatGPT (Codex).** `octet --login codex` opens OpenAI's
  sign-in page and receives the callback on `127.0.0.1:1455` (or the registered
  fallback port `1457`), then shows an octet signed-in page. The device code is
  still available, and is the default over SSH or with `--headless`.
- **On/off and Host authority for extensions.**
  - Full access (the default) runs enabled extensions as before.
  - Safe mode now starts an enabled extension once you grant host authority to
    its exact source. The grant can come from `/extensions`,
    `trusted_extensions`, `--trust-extension`, or an explicit `--extension-dir`.
  - Granted code runs with your OS permissions, outside the tool-effect broker.
    Safe mode is an approval policy, not a sandbox.
  - Existing `trusted_extensions` entries keep working.
- **Native Windows builds again.**
  - octet runs natively in Windows Terminal and conhost.
  - Shell commands run through Git Bash, and Python extensions start through
    `py -3`.
  - Pull requests publish an unsigned Windows test build. See
    [Windows](../windows.md).
- **Computer use on Linux desktops.** Computer use works on Wayland (GNOME, KDE,
  Hyprland/Omarchy, Sway) and on X11; see [Linux](../linux.md). On macOS, setup
  now finds a compatible Python instead of failing with an internal error
  (#457), provisions Cua's verified signed desktop app in octet-owned state when
  needed, and reopens setup without a session-ownership collision. Setup never
  replaces a global application or grants OS permissions.
- **Hard cost ceilings survive one bad response.** An ambiguous provider
  failure, such as a gateway 504, is charged the worst case it was admitted
  with. It no longer disables hard token and cost ceilings for the rest of the
  session.
- **Current model metadata.** Model names, prices and limits from models.dev
  refresh in the background at most every six hours, so models released after
  this build get them without an octet update. Each record is checked against
  the built-in data first, and `--offline` skips the refresh.
- **Faster on bigger machines.** The runtime's worker pool and the waves of
  parallel read-only tool calls now scale with the CPU count.

## Fixed

- The TUI workspace footer replaces the home directory with `~`, including on
  native Windows and with symlinked homes, instead of exposing the username in
  screenshots and screen shares. Only the displayed path changes.
- Deleting a session from `/resume` quit octet, because the delete key was the
  global close key, Ctrl+D. Use Ctrl+X or Delete: octet asks first, then moves
  the session to the recoverable trash (#458).
- A crash when hovering over or clicking the scrollbar with the threaded
  renderer.
- `Working` stays visible while tools run, with shimmer and elapsed time
  re-anchored after history reflow. Visible clocks no longer freeze when tall
  tool progress contracts to a short result: animation visibility follows the
  actual painted viewport, without needing a resize to wake.
- OAuth diagnostics omit unrecognized reflected codes. Subscription refresh
  locks survive credential replacement on Windows as well as Unix.
- Live price checks protect positive cache and effective reasoning buckets,
  including output-price fallback, in addition to input/output prices.
- `/status` throughput is measured end to end, and is no longer inflated for
  hidden reasoning.
- Requests honour `NO_PROXY` when a lower-case `no_proxy` is also set.
- Parallel writers to one file are serialized on Linux and macOS.
- A rejected model discovery now names the HTTP status and the provider's
  message, such as an Anthropic key that needs a workspace ID (#454).
- On native Windows the computer-use menu opens and **Check status** reports.
  Before, the menu stayed blank, then fell back to an argument prompt, and the
  check failed with `internal error`.
- Starting octet in Windows Terminal no longer leaves `]11;rgb:…` in the
  composer. Native Windows no longer queries the terminal background, so Auto
  uses its neutral fallback there; pick light or dark with `/theme`.
- On Windows and WSL the queued-message hint says Alt+Q, the key that restores
  a queued message there, instead of Alt+Up.

## Availability and limits

- **Qualification is not release approval.** Local source tests, trace replay
  and macOS dogfood do not replace fresh native Windows, Linux-desktop, physical
  terminal, first-run/privacy/shutdown or live-provider acceptance. Merge and tag
  approval is a separate maintainer gate; nothing here authorizes publication.
- **Extraction is staging.** Product manifests and reproducible bundles do not
  change source ownership: octet remains the source of truth. This local RC
  restores Tern through #501; it is not a published feature.
- **Windows, observed on unsigned candidates.** Two release candidates were
  built and exercised on native Windows x64. Computer use no longer hangs
  under octet, the terminal background query is not sent, and the
  queued-message hint names the key that works there. Three things remain
  unqualified: a multi-line paste submits once per line, the block cursor
  visibly flickers while streaming, and computer-use setup and status had no
  visible report until a further fix landed. The full record is
  `docs/qualification/v0.8.2-windows-rc.md` in the repository.
- **Planned distribution.** After approval, native archives and the installer
  target macOS (Apple silicon and Intel) and GNU/Linux x86-64, with
  `@skaft/octet@0.8.2` on npm. No 0.8.2 publication is established by this draft.
- **Windows.** There is no published Windows release. Pull-request builds are
  unsigned test artifacts. A multi-line paste submits once per line; use
  `@file` references for long text.
- **Native-history rebuilds.** Structural clear/replay can reset your terminal's
  reading position; replay work grows with history. PageUp and `--mouse app` use
  a separate bounded semantic viewport.
- **Source builds.** These need Rust 1.88 or newer.
- **What testing does not establish.** Browser sign-in and native Windows use
  are qualified by manual testing only. Live-provider coverage, qualification
  across physical terminals, and long-duration use are not established by
  source tests or package smoke.
