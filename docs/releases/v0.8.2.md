# octet 0.8.2

This release sets up and configures every extension from `/extensions`, adds
GPT-6.1 Sol and browser sign-in for ChatGPT (Codex), lets safe mode run the
extensions you grant, and restores the native Windows build.

## Highlights

- **Everything in `/extensions`.** Choosing an extension opens its options menu:
  - set up computer use end to end;
  - control the browser;
  - choose Brave Search or SearXNG for web search;
  - manage subagent workers;
  - add, edit or remove MCP servers through a guided form.

  Actions show their steps live and can be cancelled with Esc. Extension slash
  commands are gone from the terminal UI; typing one names the extension to
  open instead.
- **GPT-6.1 Sol.**
  - On ChatGPT (Codex) sign-in it leads the fallback model list and starts at
    low reasoning. Ultra appears only when your account advertises it.
  - On an OpenAI API key it offers low through max reasoning, a 1.05M-token
    context and 128K output tokens.
- **Browser sign-in for ChatGPT (Codex).** `octet --login codex` opens OpenAI's
  sign-in page and receives the callback on `127.0.0.1:1455` (or the registered
  fallback port `1457`), then shows an octet signed-in page. The device code is
  still available, and is the default over SSH or with `--headless`.
- **On/off and Host authority for extensions.**
  - Full access (the default) runs enabled extensions as before.
  - Safe mode now starts an enabled extension once you grant host authority to
    its exact source. The grant can come from `/extensions`,
    `trusted_extensions`, `--trust-extension`, or an explicit `--extension-dir`.
  - Granted code runs with your OS permissions, outside the tool-effect broker.
    Safe mode is an approval policy, not a sandbox.
  - Existing `trusted_extensions` entries keep working.
- **Native Windows builds again.**
  - octet runs natively in Windows Terminal and conhost.
  - Shell commands run through Git Bash, and Python extensions start through
    `py -3`.
  - Pull requests publish an unsigned Windows test build. See
    [Windows](../windows.md).
- **Computer use on Linux desktops.** Computer use works on Wayland (GNOME, KDE,
  Hyprland/Omarchy, Sway) and on X11; see [Linux](../linux.md). On macOS, setup
  now finds a compatible Python instead of failing with an internal error
  (#457).
- **Hard cost ceilings survive one bad response.** An ambiguous provider
  failure, such as a gateway 504, is charged the worst case it was admitted
  with. It no longer disables hard token and cost ceilings for the rest of the
  session.
- **Current model metadata.** Model names, prices and limits from models.dev
  refresh in the background at most every six hours, so models released after
  this build get them without an octet update. Each record is checked against
  the built-in data first, and `--offline` skips the refresh.
- **Faster on bigger machines.** The runtime's worker pool and the waves of
  parallel read-only tool calls now scale with the CPU count.

## Fixed

- The TUI workspace footer replaces the home directory with `~`, including on
  native Windows and with symlinked homes, instead of exposing the username in
  screenshots and screen shares. Only the displayed path changes.
- Deleting a session from `/resume` quit octet, because the delete key was the
  global close key, Ctrl+D. Use Ctrl+X or Delete: octet asks first, then moves
  the session to the recoverable trash (#458).
- A crash when hovering over or clicking the scrollbar with the threaded
  renderer.
- `Working` stays visible while tools run.
- `/status` throughput is measured end to end, and is no longer inflated for
  hidden reasoning.
- Requests honour `NO_PROXY` when a lower-case `no_proxy` is also set.
- Parallel writers to one file are serialized on Linux and macOS.
- Files tab search in the web UI skips build output, dependencies and VCS
  directories, stops after 3 seconds, and matches non-ASCII text
  case-insensitively (#459).
- A rejected model discovery now names the HTTP status and the provider's
  message, such as an Anthropic key that needs a workspace ID (#454).
- On native Windows the computer-use menu opens and **Check status** reports.
  Before, the menu stayed blank, then fell back to an argument prompt, and the
  check failed with `internal error`.
- Starting octet in Windows Terminal no longer leaves `]11;rgb:…` in the
  composer. Native Windows no longer queries the terminal background, so Auto
  uses its neutral fallback there; pick light or dark with `/theme`.

## Availability and limits

- **Platforms.** Native archives and the installer target macOS (Apple silicon
  and Intel) and GNU/Linux x86-64. npm publishes `@skaft/octet@0.8.2`.
- **Windows.** There is no published Windows release. Pull-request builds are
  unsigned test artifacts. A multi-line paste submits once per line; use
  `@file` references for long text.
- **Source builds.** These need Rust 1.88 or newer.
- **What testing does not establish.** Browser sign-in and native Windows use
  are qualified by manual testing only. Live-provider coverage, qualification
  across physical terminals, and long-duration use are not established by
  source tests or package smoke.
