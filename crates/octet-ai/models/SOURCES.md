# Built-in catalog sources

The built-in endpoint/protocol catalog is a checked-in snapshot. Last audited: **2026-08-21**.

Human-facing model identity, provider-scoped capability supplements and trusted
provider pricing are generated by
`crates/octet-ai/build.rs` from checked-in models.dev snapshots. Normal builds
never contact the network and therefore remain reproducible/offline:

- `models/models-dev-names.json` contains the canonical display-name registry;
- `models/models-dev-pricing.json` contains provider-scoped rates extracted from
  `https://models.dev/api.json`;
- `models/models-dev-capabilities.json` preserves names, limits, modalities, tools,
  structured output, exact reasoning options and interleaved-reasoning assertions;
- `models/models-dev-source.json` records the source URL and SHA-256; and
- rates are stored as integer microdollars per million tokens, converted from
  models.dev's dollars-per-million values during the explicit snapshot refresh.

The pricing snapshot is intentionally limited to octet's built-in providers. A
provider/model route absent from the snapshot remains unpriced unless an
explicit `CatalogConfig` or provider-specific override supplies rates. This is
fail-closed for subagent cost ceilings: unknown pricing cannot silently be
borrowed from another provider. Refresh the pricing snapshot only as a reviewed
maintainer operation with
`scripts/refresh-models-dev-pricing.py`; do not add network access to `build.rs`
or runtime.

- Protocol request/response capabilities are constrained by the repository API docs under `docs/research/apidocs/`.
- `gpt-4o-mini` text pricing uses $0.15/M input, $0.60/M output, and $0.075/M cached input, represented as 150,000 / 600,000 / 75,000 microdollars per million tokens.
- `gpt-5.4-mini` pricing uses $0.75/M input, $4.50/M output, and $0.075/M cached input. OpenAI does not separately bill cache writes for this route.
- `gpt-6-astra` is an explicit Responses contract observation rather than a generated models.dev entry: 1,050,000 context, 128,000 output, text/image input, text output, and `low` through `max` reasoning. Base input/cache-read/cache-write/output rates are $10/$1/$12.50/$50 per million; above 272K input they are $20/$2/$25/$75.
- The Codex inventory observed with compatibility client `0.153.2` publishes Astra's `low` through `ultra` reasoning levels as objects, defaults to `low`, and separately reports `use_responses_lite`, `multi_agent_version`, visibility, and API support. octet retains its 872K advertised input maximum, budgets 272K actively, treats a successful account inventory—not the model name or plan—as authoritative for dynamic Lite/V2 features, and maps explicitly selected Ultra to `max` model effort only with V2 delegation.
- Anthropic text pricing records the published input/output/cache-read/5-minute-write rates and the explicit one-hour write rate of 2× input: Sonnet 4.5 and 4.6 use $3/$15/$0.30/$3.75/$6; Opus 4.8 uses $5/$25/$0.50/$6.25/$10; Fable 5 uses $10/$50/$1/$12.50/$20, all per million tokens.
- The audio seed entry intentionally has `pricing: null` because this repository has no authoritative price snapshot for its separate text/audio token classes.

Endpoint auth, protocol compatibility, and explicit catalog pricing remain octet
configuration. The models.dev supplement fills missing metadata only for actual
inventory-returned built-in routes. Provider API assertions (including false,
unknown and malformed values) block replacement for their semantic field group.
Exact provider/model keys never borrow capabilities or prices by leaf ID.
Configured catalogs and custom metadata keep precedence; Codex account inventory
never inherits this supplement. Names and limits do not select a protocol or
reasoning encoding. The existing declaration-owned wire profiles constrain which
semantic controls may be consumed, and native Messages/budget contracts are not
inferred from a generic reasoning boolean.

## Reasoning contract supplement (2026-09-05)

The Cerebras route fallback for an inventory-returned **`qwen-3.8-27b`** uses
`none`, `low`, `medium`, `high` (default `high`) and replays separated reasoning
as `assistant.reasoning`. Source: [Cerebras reasoning documentation](https://inference-docs.cerebras.ai/capabilities/reasoning),
reviewed separately from the older catalog/pricing snapshot. This does not add
an invented model inventory, limits, prices, or a live-instance acceptance claim.
The unhyphenated `qwen3.8-27b` is not this documented route identifier.

Synthetic custom-server Qwen profiles are independent endpoint assertions, not
Cerebras contracts. Their fixture provenance is recorded in
`crates/octet-coding-agent/fixtures/providers/thinking-hotfix.json`.

## Rich metadata refresh (v0.7.6)

Saved public `https://models.dev/api.json` source SHA-256:
`922e6f74093fa6562b29dde8cb145f34bf7f42f70e7cc46cc4660a7ace759869`.
It contains 822 selected capability routes and 382 canonical names. A binary-search
index decodes only the requested capability record; builds and runtime never fetch
models.dev. Reproduce or validate the four checked-in outputs with:

```sh
python3 scripts/refresh-models-dev-pricing.py --source /path/to/saved-api.json
python3 scripts/refresh-models-dev-pricing.py --source /path/to/saved-api.json --check
python3 scripts/test_refresh_models_dev_metadata.py
```

An explicit refresh without `--source` fetches only the fixed public HTTPS URL,
without credentials or environment proxies, rejects redirects and responses above
16 MiB, and uses a 30-second socket timeout. Automated callers must also impose a
total command deadline. Failed source validation and `--check` do not write outputs.
The pinned digest identifies reviewed evidence, not a live availability promise.

A sparse direct DeepSeek `deepseek-flash` entry now receives **DeepSeek V4.1 Flash**,
1,000,000 context / 384,000 output, text/image input, tools, structured output and
the exact Off/low/high/max choices. It does not gain medium or xhigh. These semantic
options use the existing DeepSeek native `thinking.type` and exact effort profile,
including required `assistant.reasoning_content` replay; they are not a Qwen
profile or a new hardcoded model alias. Production registration admits
discovery before adding static fallbacks. The historical DeepSeek selector (also
when `OCTET_DEEPSEEK_MODEL` changes its transport name) copies admitted metadata;
explicit environment limits still override that selector's limits. Existing raw
version-1 provider caches gain this enrichment without persisting synthesized
fields or changing account/URL isolation. The snapshot's absent default stays absent
unless an existing documented route default remains in the exact option set.

### Pricing review and uncertainty

The refreshed integer-rate snapshot has 798 routes: 47 added, 23 removed, 40
changed (38 OpenRouter, two Fireworks) versus the previous published source.
Examples: OpenRouter `deepseek/deepseek-v4-pro` changes input/output from
417,252/834,504 to 829,458/1,658,916 microdollars per million; Fireworks
`accounts/fireworks/models/deepseek-v4-flash-0731` changes input/output/cache-read
from 140,000/280,000/28,000 to 220,000/660,000/7,000. These are saved catalog
quotes for those routes, not direct DeepSeek prices.

**Direct DeepSeek pricing remains unknown**, including legacy V4 fallbacks.
The saved catalog quotes Flash at $0.15/$0.60/$0.003 per million
input/output/cache-read tokens, while the [official tariff](https://api-docs.deepseek.com/quick_start/pricing)
now distinguishes peak/off-peak periods. This snapshot cannot verify schedule
accounting or a safe maximum. Direct flat quotes are therefore excluded and the
legacy override no longer bypasses uncertainty. Price-dependent hard cost ceilings
must fail closed without explicitly configured trusted rates. Other providers'
route-specific quotes and configured pricing retain their existing precedence.
No schedule, free pricing, or live inference qualification is invented here.
