# octet 0.8.1-rc.1 — local dogfood candidate

This unpublished candidate collects the in-session setup, theme, window-title,
and Kitty inline-image changes since 0.8.0.

## Highlights

- Configure providers through `/setup` during a session while preserving the
  active model and session.
- Discover user-defined TOML themes in `/theme`.
- Keep the terminal window title synchronized with the active session name.
- Prevent Kitty inline-image transmission from advancing the cursor into the
  composer.

## Candidate notes

This is a local-only dogfood build, not a published release. The Kitty cursor
change still needs visual confirmation in a Kitty-compatible terminal.
