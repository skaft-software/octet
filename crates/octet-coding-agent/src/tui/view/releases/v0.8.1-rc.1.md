# octet 0.8.1-rc.1

This unpublished candidate is prepared for local dogfooding only. It collects
in-session `/setup`, user-defined TOML theme discovery, session-name terminal
titles, Kitty inline-image cursor handling, and RC-compatible source extension
pins since 0.8.0. No binary or extension package from this candidate is
published.

- Fix Shift+Tab thinking cycling: one ascending, total cycle rule now serves
  the idle and active-run paths, so the gesture always advances instead of
  silently doing nothing on a token-budget or no-longer-advertised selection.
- Give the `Working` and `Thinking` activity labels one shared shimmer clock, so
  they can no longer shimmer differently or freeze mid-row. Retry, compaction,
  and provider lifecycle labels stay timer-only.

## Build locally

From this source checkout, build the debug binaries and run octet directly:

```sh
cargo build --offline --locked -p octet-coding-agent --bins
./target/debug/octet --version
```

Use `--extension-dir ./extensions` when running with extension sources from this
checkout. For example:

```sh
./target/debug/octet --extension-dir ./extensions --enable-extension octet-subagents
```

Do not use `cargo install` or a global installer.
