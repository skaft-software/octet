# octet 0.10.6

## [0.10.6] - 2026-11-20

### Added

- Archive Pi v3 transcripts as private HTML with `octet sessions import --transcript-only`, without replaying provider state.
- Watch nested tool calls run and finish inside their Codemode card, including failures the script catches.
- Click a tool-card header to expand or collapse just that card; Ctrl+O still changes disclosure for the whole transcript.

### Fixed

- Preserve the terminal's cursor shape and blink settings in both fullscreen and inline modes.
- Import Pi 1.5 chat sessions with system messages and turn timings without reusing foreign instructions or tool definitions.
- `--no-skills` skips automatic skill discovery while still loading paths explicitly passed with `--skill-dir`.
- Use bundled `pi-claude-code` models, streamed thinking, and tool results through a reviewed Pi setup, without importing credentials.
- Ctrl+G opens the idle draft in your external editor and keeps the draft on failure.
- RPC can list forkable prompts, fork or clone the session, export redacted HTML, and clear queued steering and follow-ups.
- Scrolling the fullscreen transcript keeps inline images aligned by reusing image data already in the terminal.
- Tern keeps captured Bash and exec output behind verbose mode even when an extension renders the tool card.
